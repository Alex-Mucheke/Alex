## 👋 Hi, I'm Alex

I'm a **software developer and Computer Science student at Chuka University, Kenya**. I build the systems that businesses actually run on: point of sale, delivery tracking, learning platforms, payment flows and the APIs behind them.

I don't just write code. I sit with the business problem, design the architecture and database, build the API, ship a clean interface, and connect the services that make it work in real life, **including M-Pesa**.
